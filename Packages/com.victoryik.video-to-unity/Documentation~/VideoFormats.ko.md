# 어떤 영상을 넣으면 되나

## 이미 검정 배경 MP4가 있을 때

그대로 Unity에 가져온 뒤 이펙트 창에서 VideoClip을 고른다.

| 영상 성격 | 선택할 합성 방식 | 결과 |
|---|---|---|
| 빛, 스파크, 네온 | Additive / 가산 합성 | 검정은 영향을 주지 않고 빛을 더함. 검정 그림자나 불투명 배너에는 부적합 |
| 일반 색 이펙트 + 검정 바탕 | BlackKey / 검정 제거 | 검정과 가까운 픽셀을 투명하게 추정. 임계값과 부드러움을 조절 |
| 초록 등 단색 배경 | ChromaKey / 색상 제거 | 선택한 색과 가까운 픽셀을 투명하게 추정 |
| 화면 전체 불투명 영상 | Opaque | 알파 없이 그대로 표시 |

**검정 배경과 검정 그림이 같은 픽셀 값이면 어느 것이 배경인지 알 수 없다.** 키 모드는 즉시 쓸 수 있는 근사 처리다. 검정 배너·그림자·부드러운 경계를 정확하게 보존해야 하면 알파 원본을 전달한다.

한 번 처리해서 저장하려면 [MP4 배경 분리](BackgroundRemoval.ko.md)를 사용한다. 여러 프레임의 테두리에서 배경색을 분석하고 가장자리 연결·보호 사각형을 적용해 Packed MP4 또는 알파 WebM을 만든다. 복잡한 배경의 의미 기반 AI 분리나 원본 레이어 복원은 아니다. 자동 판별 신뢰도가 낮으면 지울 색을 직접 선택한다.

## 알파 원본을 만들 수 있을 때

권장 제작 원본은 **ProRes 4444 MOV · RGB+Alpha · Straight**다. 용도에 맞는 해상도와 고정 FPS로 내보낸다. 1920×1080 / 30 또는 60fps는 예시이며 도구가 모든 영상을 이 규격으로 강제하지 않는다.

- 투명할 배경 레이어는 끈다.
- 남겨야 하는 검정 글자, 배너와 그림자는 유지한다.
- premultiplied로 출력했다면 에셋의 Premultiplied를 맞춰야 한다. 처음에는 Straight를 권장한다.
- 원본 MOV, 확인용 MP4, FPS·길이·루프 여부·용도를 적은 메모를 전달하면 된다.

## 변환 출력 선택

**Packed H.264 MP4**는 왼쪽에 색, 오른쪽에 회색 알파를 넣는다. 에셋의 PackedAlpha 모드가 둘을 합친다. 원본 너비의 두 배가 디코딩되므로 기기 해상도 한도를 확인한다. 일반 동영상 플레이어에서는 색과 마스크가 나란히 보이는 것이 정상이다.

**Alpha WebM**은 VP8 알파를 사용한다. NativeAlpha 모드로 재생하며 Unity에 가져올 때 Keep Alpha와 Transcode를 설정한다. Linux 또는 Unity의 투명 VideoClip 가져오기 경로에 유용하다. OS와 기기별 지원 범위는 다르다.

변환은 FFmpeg/ffprobe를 사용하는 **개발 PC의 Editor 작업**이다. 실행 파일은 별도로 준비하며 게임 빌드에는 변환 도구가 포함되지 않는다. Python·Codex·AI 플러그인·상용 AVPro 설치는 필요 없다. [FFmpeg 다운로드](https://ffmpeg.org/download.html)

## 색과 화질

변환 출력은 압축 영상이다. ProRes 원본과 비트 단위로 같지 않다. 작은 글자, 날카로운 색 경계, 반투명 테두리는 실제 배경 위에서 확인한다. PackedAlpha의 회색 마스크는 색이 아닌 데이터이므로 Linear 프로젝트에서는 감마 보정을 적용한다. 플랫폼 디코더의 출력이 다를 경우 Correct Packed Alpha Gamma 설정을 검토한다.

## 씬 전환

이펙트 재생과 씬 교체는 별개다. 플러그인은 영상 재생 이벤트와 Timeline 연결을 제공한다. 화면이 가려지는 시점에 게임의 씬 로딩 코드를 연결한다. 임의 영상 모양을 분석해 완벽한 전환 마스크나 로딩 대기 구간을 자동 생성하지 않는다.
