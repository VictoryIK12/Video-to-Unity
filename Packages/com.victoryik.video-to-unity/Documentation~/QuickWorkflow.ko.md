# 영상 넣고 씬에 추가하기

**Tools → Video to Unity → 영상으로 이펙트 만들기**를 엽니다. 탐색기나 Unity Project 창에서 영상 하나를 끌어 넣거나 **파일 선택**을 누릅니다.

설치된 FFmpeg·ffprobe가 있으면 자동 연결합니다. 찾지 못하면 **영상 도구 자동 준비**로 준비하거나 **도구 경로 직접 지정**을 펼칩니다. Windows x64의 자동 준비는 버튼을 눌렀을 때만 다운로드하고 확인한 실행 파일을 사용자 캐시에 저장합니다. 프로젝트나 시스템 PATH는 바꾸지 않습니다. 다른 운영체제에서는 설치된 도구를 찾거나 직접 경로를 연결합니다.

## 추천 확인

| 추천 | 선택 기준 |
|---|---|
| 원본 투명도 유지 | 알파를 담는 형식이거나 분석한 장면에 실제 투명도가 있습니다. 전체 변환에서도 알파를 검증합니다. |
| 단색 배경 제거 | 여러 장면에서 테두리의 배경색이 일정합니다. 그 색의 그림까지 지워지는지 확인하세요. |
| 원본 그대로 | 일정한 배경색을 확신할 수 없습니다. 제거할 색을 직접 선택할 수 있습니다. |

빛·글로우 영상은 **빛·글로우 밝게 합성**을 직접 선택할 수 있습니다. RGB가 왼쪽, 알파가 오른쪽인 영상에는 **좌우 RGB + 알파 영상**을 선택합니다. 파일 이름만으로 이 두 방식을 추정하지 않습니다.

## 결과 확인

원본과 체커보드 위의 적용 결과를 비교합니다. **다른 시간 보기**를 움직이면 해당 장면을 자동 갱신합니다. 이 화면은 시간별 정지 화면이며 연속 재생은 씬에서 Play로 확인합니다. 설정을 바꾼 뒤에는 새 결과가 준비될 때까지 씬 추가 버튼이 잠깁니다.

원치 않는 부분이 지워졌다면 **색과 보호 영역 조절**을 엽니다. 배경색을 직접 정하거나 원본에서 찍을 수 있습니다. 오른쪽 결과에서 드래그하면 남길 영역을 그릴 수 있습니다. 보호 영역은 클립 전체에서 고정되며 움직이는 대상을 추적하지 않습니다. 새 영상을 넣으면 이전 영상의 보호 영역을 지웁니다.

## 씬에 추가

**화면 전체**, **선택한 UI 안에**, **게임 공간의 평면** 중 하나를 고른 뒤 **씬에 추가**를 누릅니다. UI를 고른 경우 씬의 Canvas를 지정합니다. 월드 평면은 Scene 뷰가 보고 있는 지점에 배치하며 너비를 조절할 수 있습니다.

필요한 복사나 변환 후, 새 영상과 이펙트 에셋을 `Assets/VideoToUnity/Generated`에 저장하고 씬 오브젝트를 만듭니다. 기존 이름과 겹치면 새 이름을 사용하며 원본은 수정하지 않습니다. WebGL이 현재 빌드 대상으로 선택되어 있으면 재생 영상은 `Assets/StreamingAssets/VideoToUnity`에 저장합니다. 브라우저 코덱·자동재생·배포 조건은 별도로 확인하세요.

씬에서 **Play**를 누르면 재생합니다. 기본 이펙트는 소리 없이 재생합니다. **Ctrl+Z**는 만든 씬 오브젝트를 되돌리며, 다시 쓸 수 있는 영상과 에셋은 남깁니다. 씬을 저장해야 배치도 보존됩니다.

변환 중에는 추가 버튼이 잠기며 취소할 수 있습니다. 창을 닫거나 Play Mode에 들어가면 진행 중 작업을 취소합니다. 변환 중 활성 씬이 바뀌면 자동 배치를 멈추고 저장된 에셋을 유지합니다. 원하는 씬에서 다시 추가하세요.

색으로 합쳐진 MP4를 원래 레이어로 완벽히 복구하지는 못합니다. 알파 원본이 있다면 그대로 활용하세요. 입력·출력 형식의 자세한 제한은 [영상 형식](VideoFormats.ko.md), 색 제거의 제한은 [배경 분리](BackgroundRemoval.ko.md)를 확인하세요.

## Video Effect Asset은 무엇인가요?

Unity의 `ScriptableObject` 기능으로 저장한 **Video to Unity 전용 설정 에셋**입니다. 새로운 영상 코덱이나 Unity 공식 영상 포맷이 아닙니다. 실제 영상은 별도 `video.mp4` 등의 파일에 있고, `effect.asset`에는 그 영상의 참조와 합성 방식·반복 재생 등의 설정이 들어 있습니다.

Inspector의 흰색 안내 상자는 사용 설명입니다. `The main object name ... should match the asset filename ...`라는 노란 경고는 preview.4에서 내부 이름을 원본 영상 이름으로 덮어쓰던 버그이며, preview.5에서 수정했습니다. 기존 파일에는 Unity의 **Fix object name**을 한 번 누르면 됩니다. 영상 파일을 다시 변환할 필요는 없습니다.

## 자동 준비에 사용하는 배포본

Windows x64는 FFmpeg 공식 다운로드 페이지에서 안내하는 Gyan.dev의 **9.0.2 essentials** 배포본을 사용합니다. 고정된 GitHub 릴리스에서 약 115 MB를 내려받고, 배포자 체크섬과 대조한 SHA-256 값을 검사한 뒤 FFmpeg·ffprobe와 라이선스 안내만 사용자 캐시에 풉니다. 버전과 필요한 인코더 확인에 성공해야 연결합니다. 배포본은 이 패키지에 포함하지 않습니다.

- [FFmpeg 공식 다운로드 안내](https://ffmpeg.org/download.html)
- [Gyan.dev 9.0.2 배포본과 라이선스](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2)

자동 설치 위치는 `%LOCALAPPDATA%/VideoToUnity/Tools/ffmpeg-9.0.2-win64`입니다. 설치 경로가 이미 사용 중이면 새 폴더를 만들고 그 경로를 기억합니다. 취소·다운로드 실패·검증 실패 때는 이번 작업의 임시 폴더만 정리합니다. 네트워크가 차단된 환경은 미리 설치한 FFmpeg·ffprobe 경로를 직접 지정할 수 있습니다.
